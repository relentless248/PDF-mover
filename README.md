# PDF 自动归类工具

一个基于 Python + Tkinter 的桌面工具，用于将大量 PDF 报告文件 **自动识别、匹配并归档** 到对应的项目文件夹及其目标子目录中。

> 本工具采用「配置驱动」设计：项目编号格式、目标子目录名、OCR 识别参数等关键差异均可在图形界面中配置，无需修改源码，可复用于不同组织的档案管理场景。

## 功能特性

- **OCR 自动识别**：基于 Tesseract 对 PDF 进行文字识别，提取项目编号
- **智能匹配归档**：按项目编号自动定位项目文件夹，复制/移动至目标子目录
- **复杂场景处理**：多项目编号、关联编号（see）、未找到重命名、全自动批处理
- **可视化配置**：在界面中自定义「编号格式」「识别参数」「目标子目录名」，无需改代码
- **记录留痕**：自动生成 Excel 归档记录与多项目对账表
- **安全校验**：目标路径白名单、原子写入、文件占用重试、临时文件自动清理

## 环境要求

- **仅支持 Windows**（启动脚本、`os.startfile`、Tesseract / Poppler 均使用 Windows 版本）
- Python 3.10+（或使用项目自带嵌入式运行时）
- [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki)（OCR 引擎）
- [Poppler for Windows](https://github.com/oschwartz10612/poppler-windows/releases)（PDF 渲染）

## 安装

### 方式一：一键安装（推荐）

1. 双击 `install_deps.bat`
   - 自动安装 Python 依赖（`pdf2image`、`pytesseract`、`Pillow`、`openpyxl`）
   - 检查并提示 Tesseract / Poppler 的安装位置

### 方式二：手动安装

1. 安装 Python 3.10+，执行：
   ```bash
   pip install -r requirements.txt
   ```
2. 下载 Tesseract OCR，解压到项目根目录 `Tesseract-OCR/`
3. 下载 Poppler for Windows，解压到项目根目录（如 `poppler-*/`，版本号目录名可在配置中修改）

## 启动

```bash
run.bat
```

首次启动后，在界面中：
1. 点击「添加根目录」选择项目文件夹所在的父目录，等待索引构建完成
2. 点击「浏览」选择 PDF 源文件夹
3. 点击左侧列表中的 PDF 开始识别；或勾选「自动运行」批量处理

## 配置说明

点击主界面右上角「⚙ 设置」打开配置面板，包含四类配置：

### 1. 项目编号格式
以「段」为单位可视化建模（固定值 / 字母 / 数字 / 自定义字符集），自动生成正则并实时预览、测试。也提供「高级模式」直接编辑正则。

内置默认（通用占位）：`[A-Z]{2,5}\d{6,10}`（请改为贵组织的编号规则）

### 2. 识别参数
- **语言**：简体中文 / 英文独立勾选，可单选或同时选择
- **数值参数**空白点击输入框，实时显示推荐范围及过大/过小的后果
- 识别 DPI、最大页数、各阶段超时
- 未识别时是否自动旋转重试及旋转步长
- OCR / 搜索缓存条数

### 3. 归档与子目录
- **目标子文件夹名**：匹配规则为 **不区分大小写、忽略空格/下划线/横线等分隔符差异**。例如填 `Data`，可匹配 `data`、`Data`、`01 Data`、`data_files` 等
- 归档文件名（默认 `TDS`）
- 文件夹匹配规则

### 4. 年份管理
- 年份提取：编号前缀长度、世纪前缀、未识别年份目录名
- 可用年份分类：预置到主界面「分拣年份」下拉

> - 每页顶部提供独立的「恢复本页默认」
> - 关闭设置窗口即自动保存并生效
> - 主界面「❓ 帮助」内置完整使用说明

> 所有配置项均提供默认值，未修改时行为与内置默认完全一致。

## 常见问题

**找不到 Tesseract / Poppler？**
确保 `Tesseract-OCR/` 与 `poppler-*/` 目录在项目根目录下，或运行 `install_deps.bat` 检查。

**某编号未被识别？**
检查编号是否匹配「项目编号格式」中的规则，可在设置面板用「测试」功能验证。

**子目录未命中？**
检查目标子文件夹名是否正确（匹配忽略大小写与空格/下划线/横线等分隔符差异）。
